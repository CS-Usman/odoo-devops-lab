DevOps Server Monitor

Dashboard module for the odoo-devops-lab project. Tracks CPU, RAM, disk, network and disk I/O, PostgreSQL health, Odoo filestore usage, and Docker container stats when the Docker CLI is available.

  • DevOps Monitor → Dashboard — latest health snapshot
  • History / Trends — time-series graphs from cron snapshots
  • GET /devops/health — lightweight CI check
  • GET /devops/metrics — full JSON metrics payload

Optional: install psutil in the Odoo environment for richer host metrics. Without it, the module falls back to reading /proc on Linux.

To collect Docker container stats from Odoo running in Docker, mount /var/run/docker.sock and install the Docker CLI in the container.
